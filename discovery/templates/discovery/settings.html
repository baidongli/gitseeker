如何创建 Token

  1. 访问 github.com/settings/tokens
  2. 点击 Generate new token → Fine-grained personal access token
  3. 填写名字（如 gitseeker），Expiration 选个合适的时长
  4. Repository access 选 Public Repositories (read-only) 即可
  5. Permissions 留默认（已经够用）
  6. 点 Generate token，复制生成的 token 粘贴到上面

Token 只用于读取公开仓库信息，存在本地 SQLite，不会上传到任何地方
